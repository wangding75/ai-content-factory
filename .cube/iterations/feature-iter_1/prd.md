# Iteration 1 PRD：通用内容项目入口

## 1. 功能概述

本次迭代建立 AI Content Factory 的最小内容项目管理入口，让运营者可以创建 Novel 类型的内容项目，并围绕项目维护基础信息、内容类型、PromptTemplate 和默认 LLM Provider 配置。

本迭代包含以下功能点：

- 内容项目创建、查看、编辑、删除与列表浏览。
- 内容类型选择，首期仅开放 Novel，但入口和展示需保持内容类型无关。
- 内容项目基础信息配置，包括名称、目标平台、目标内容数量、默认生成参数。
- PromptTemplate 基础保存与查看入口。
- 默认 LLM Provider 配置入口，并支持 API Key 安全保存。
- Web 管理台基础布局，用于承载项目入口、项目详情、PromptTemplate 和 LLM 配置页面。

## 2. Functional Requirements

### 内容项目管理

#### FR-001 创建内容项目（P0）

运营者可以创建一个内容项目。

- 输入：项目名称、内容类型、目标平台、目标内容数量、默认生成参数。
- 输出：创建成功后生成内容项目，并可在项目列表中看到该项目。
- 异常处理：
  - 项目名称为空时，提示用户填写项目名称。
  - 内容类型未选择时，提示用户选择内容类型。
  - 目标内容数量不合法时，提示用户修正为有效数量。
  - 创建失败时，向用户展示失败提示，且不得产生半完成的可见项目。

#### FR-002 选择 Novel 内容类型（P0）

运营者在创建项目时可以选择内容类型，首期只开放 Novel。

- 输入：用户在内容类型选择入口中选择 Novel。
- 输出：新项目被标记为 Novel 类型，并以通用 ContentProject 形式进入后续管理。
- 异常处理：
  - 当前没有可用内容类型时，创建入口应提示暂无可用内容类型。
  - 不允许用户通过界面选择未开放内容类型。

#### FR-003 查看项目列表（P0）

运营者可以查看已创建的内容项目列表。

- 输入：进入项目列表页。
- 输出：展示项目名称、内容类型、目标平台、目标内容数量、项目状态、创建时间或更新时间等摘要信息。
- 异常处理：
  - 没有项目时，展示空状态，并引导用户创建项目。
  - 加载失败时，展示错误提示和重试入口。

#### FR-004 查看项目详情（P0）

运营者可以进入某个项目详情页查看完整基础信息。

- 输入：从项目列表选择一个项目。
- 输出：展示项目名称、内容类型、目标平台、目标内容数量、默认生成参数、关联 PromptTemplate 和默认 LLM Provider 配置入口。
- 异常处理：
  - 项目不存在时，提示项目不存在或已被删除。
  - 加载失败时，展示错误提示和返回列表入口。

#### FR-005 编辑内容项目基础信息（P1）

运营者可以编辑项目的基础配置。

- 输入：项目名称、目标平台、目标内容数量、默认生成参数。
- 输出：保存成功后，项目详情和列表摘要展示最新信息。
- 异常处理：
  - 必填项为空或格式不合法时，提示用户修正。
  - 保存失败时，保留用户已输入内容，并展示失败提示。

#### FR-006 删除内容项目（P1）

运营者可以删除不再需要的内容项目。

- 输入：用户对某个项目触发删除动作并确认。
- 输出：项目从列表中移除，后续不可再进入详情页。
- 异常处理：
  - 用户取消确认时，不删除项目。
  - 删除失败时，项目仍保留在列表中，并展示失败提示。

### PromptTemplate 管理入口

#### FR-007 保存 PromptTemplate（P0）

运营者可以保存与内容生产相关的 PromptTemplate。

- 输入：模板名称、适用内容类型、适用 Agent 或用途、模板内容、版本信息。
- 输出：保存成功后可在 PromptTemplate 管理入口看到该模板。
- 异常处理：
  - 模板名称或模板内容为空时，提示用户补充。
  - 内容类型未选择时，提示用户选择适用内容类型。
  - 保存失败时，保留用户输入内容，并展示失败提示。

#### FR-008 查看 PromptTemplate 列表或详情（P1）

运营者可以查看已保存的 PromptTemplate。

- 输入：进入 PromptTemplate 管理入口，或从项目详情进入关联入口。
- 输出：展示模板名称、适用内容类型、适用 Agent 或用途、版本和模板内容摘要。
- 异常处理：
  - 没有模板时，展示空状态，并引导用户创建模板。
  - 加载失败时，展示错误提示和重试入口。

### LLM Provider 配置入口

#### FR-009 配置默认 LLM Provider（P0）

运营者可以配置系统默认 LLM Provider，用于后续生成能力调用。

- 输入：Provider 名称、模型标识、Base URL、API Key、是否启用等基础信息。
- 输出：保存成功后，项目或系统配置入口显示当前默认 Provider。
- 异常处理：
  - Provider 名称、模型标识或 API Key 缺失时，提示用户补充。
  - 配置保存失败时，保留用户已输入的非敏感配置，并展示失败提示。

#### FR-010 安全展示 LLM Provider 配置（P0）

运营者可以查看已配置的 LLM Provider，但 API Key 不应明文展示。

- 输入：进入 LLM Provider 配置页。
- 输出：展示 Provider 名称、模型标识、Base URL、启用状态；API Key 仅展示已配置状态或脱敏信息。
- 异常处理：
  - 配置不存在时，展示未配置状态，并引导用户新增配置。
  - 加载失败时，展示错误提示和重试入口。

### Web 管理台基础布局

#### FR-011 提供管理台基础导航（P0）

运营者可以通过 Web 管理台进入项目管理、PromptTemplate 管理和 LLM Provider 配置入口。

- 输入：访问管理台首页或导航菜单。
- 输出：展示清晰的导航入口和当前页面内容区域。
- 异常处理：
  - 访问未知页面时，展示未找到提示或返回首页入口。

#### FR-012 保持核心体验内容类型无关（P0）

用户在核心项目管理、PromptTemplate 和 LLM 配置体验中看到的是通用内容项目能力，而不是小说专属管理能力。

- 输入：用户访问项目列表、项目详情、PromptTemplate 或 LLM 配置页面。
- 输出：页面文案和信息结构使用内容项目、内容类型、内容单元、模板、Provider 等通用概念；Novel 仅作为一个可选内容类型出现。
- 异常处理：
  - 如发现核心入口中出现 Book、Chapter 等小说专属概念，应视为不符合验收要求。

## 3. Non-Functional Requirements

### 安全

- NFR-001：API Key 必须安全保存，用户界面和普通查询结果不得明文展示完整 API Key。
- NFR-002：用户输入的项目名称、PromptTemplate 内容、Provider 配置等必须在系统边界进行校验，避免无效或危险输入进入系统。
- NFR-003：错误提示不得泄露 API Key、连接串或内部异常堆栈。

### 可扩展性

- NFR-004：内容类型入口必须支持未来新增 Article、Short Video、Social Post 等内容包，不得把 Novel 作为核心平台的唯一模型假设。
- NFR-005：PromptTemplate 必须能按内容类型、用途或 Agent、版本进行区分，以支持后续多内容类型和多 Agent 复用。
- NFR-006：LLM Provider 配置必须独立于具体 Agent 和内容类型，以支持后续 LLM Router 复用。

### 可用性

- NFR-007：列表、详情、表单保存场景必须提供加载、空状态、成功和失败反馈。
- NFR-008：删除内容项目必须有人工确认，避免误删。

## 4. 验收标准

- AC-001：运营者可以成功创建一个 Novel 类型的 ContentProject。
- AC-002：项目创建成功后，可以在项目列表看到该项目。
- AC-003：运营者可以进入项目详情并看到项目基础信息、内容类型、目标平台、目标内容数量和默认生成参数。
- AC-004：运营者可以编辑并保存项目基础信息，保存后列表和详情展示更新后的信息。
- AC-005：运营者可以删除内容项目，删除前必须经过确认。
- AC-006：当项目列表为空时，系统展示空状态和创建入口。
- AC-007：运营者可以保存 PromptTemplate。
- AC-008：PromptTemplate 可以按内容类型、用途或 Agent、版本进行查看或识别。
- AC-009：运营者可以保存默认 LLM Provider 配置。
- AC-010：已保存的 LLM Provider 配置不得在界面或普通查询结果中明文展示完整 API Key。
- AC-011：Web 管理台提供项目管理、PromptTemplate 管理和 LLM Provider 配置的基础导航入口。
- AC-012：核心表、核心 API、核心页面文案不得使用 book、chapter 作为核心项目和内容单元概念。
- AC-013：Novel 只作为内容类型选项或内容包扩展概念出现，不得把小说专属能力写入核心项目管理体验。
- AC-014：不实现具体 Agent 生成流程、工作流执行、发布流程和 Novel 详细设定能力。

## 5. Out of Scope

- 不实现工作流模板配置和工作流执行。
- 不实现 Agent 生成、AgentTask 执行或 LLMCallLog 记录流程。
- 不实现 Novel Pack 的世界观、人物、章节、剧情、连续性等专属能力。
- 不实现平台发布、PublishJob、PlatformAdapter 或发布回填。
- 不实现指标采集、MetricRecord 录入或策略建议。
- 不实现自动化内容生成。
- 不实现完整权限体系；认证授权如未在当前项目基础中存在，留待后续迭代。
