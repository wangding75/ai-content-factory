# Iteration 11：平台适配器与浏览器插件

> 文件定位：本文件是迭代 11 的需求评审与开发范围文档。  
> 蓝图约束：本迭代必须遵守 `00-product-blueprint.md`。  
> 开发规则：进入开发前必须完成本文件中的需求评审检查。

---

## 1. 迭代目标

建立 Platform Adapter 体系，并用浏览器插件实现番茄小说的半自动发布和基础数据采集。

---

## 2. 蓝图对齐说明

| 蓝图约束 | 本迭代对齐方式 |
|---|---|
| 核心平台内容类型无关 | 本迭代不得把小说专属逻辑写入 Core |
| 内容类型插件化 | Novel 相关能力必须放入 Novel Pack 或扩展模型 |
| 工作流可配置 | 涉及流程时必须通过 WorkflowTemplate / WorkflowRun 承载 |
| Agent 可追踪 | 涉及 Agent 时必须记录 AgentTask 和 LLMCallLog |
| 发布平台适配器化 | 涉及发布时必须通过 PublishJob / PlatformAdapter 承载 |
| 指标通用化 | 涉及数据时必须通过 MetricRecord / MetricTemplate 承载 |
| 人工节点保留 | 审稿、发布、策略等关键动作必须支持人工确认 |
| 迭代可评审 | 开发前必须完成需求评审与验收标准确认 |

---

## 3. 产品需求

- 支持插件连接后端。
- 支持从发布队列拉取待发布内容。
- 支持自动填充平台发布页。
- 保留人工最终确认发布。
- 支持基础数据采集回填。
- 支持采集失败提示。

---

## 4. 技术需求

- 实现 Chrome Extension Manifest V3。
- 实现 Content Script。
- 实现插件认证 API Key。
- 实现 FanqieAdapter 自动化能力。
- 实现 XHR 拦截或页面数据读取。
- 实现插件与后端通信。
- 实现平台适配错误日志。

---

## 5. 涉及数据模型

- `platform_adapter_config`
- `plugin_client`
- `platform_collect_log`

---

## 6. 涉及 Agent / 工作流

- 可引入 PublishFormatAgent，但不是必须。

---

## 7. 验收标准

- [ ] 插件可以安全连接后端。
- [ ] 插件可以读取待发布 PublishJob。
- [ ] 插件可以自动填充番茄发布页标题和正文。
- [ ] 人工点击平台发布按钮后，可以回填发布状态。
- [ ] 插件可以采集基础指标并写入 MetricRecord。
- [ ] 平台适配逻辑不进入 Core 层。

---

## 8. 需求评审检查项

- [ ] 平台自动化是否仍保留人工确认？
- [ ] FanqieAdapter 是否只是 Platform Adapter 的一种实现？
- [ ] 插件认证是否安全？
- [ ] 平台页面变化时是否有降级处理？

---

## 9. 本迭代明确不做

- 不做完全无人值守发布。
- 不做多平台插件全量适配。
- 不做绕过平台风控的能力。
